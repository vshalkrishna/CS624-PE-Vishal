# Input

No user input is necessary for this Hello World application to function properly. It uses only three fixed texts provided in React Native source code as inputs: my name Vishal Krishna Kumar, my degree program – MSCS, and City University of Seattle.

# Process

This app is initially launched using Expo and the React Native App component is rendered. App uses a View as the main container component. Texts representing information are rendered within the Text components which are positioned on different lines. Stylesheet makes a background yellow and positions Text elements both horizontally and vertically using flexbox properties. Text styles are responsible for size, colors, alignment and line height.

# Output

This application shows yellow filled screen with my name, my degree and my educational institution centered in black colored text.
